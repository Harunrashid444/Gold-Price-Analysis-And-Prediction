# API Documentation

Base URL: `http://localhost:<PORT>/api`

## Authentication

All authentication endpoints are located under `/api/auth` and use standard JSON request bodies. Session management is handled via HTTP-only cookies.

### `POST /api/auth/register`
Register a new user account.
- **Body**: 
  ```json
  {
    "email": "user@example.com",
    "password": "Password1",
    "name": "John Doe"
  }
  ```
  *(Name is required and must be 2–80 characters. Password must be at least 8 characters and include at least one letter and one number).*

### `POST /api/auth/login`
Log in an existing user.
- **Body**: 
  ```json
  {
    "email": "user@example.com",
    "password": "Password1"
  }
  ```
- **Response**: Sets an HTTP-only cookie containing the authentication token.

### `POST /api/auth/logout`
Log out the currently authenticated user.
- **Response**: Clears the authentication cookie.

### `GET /api/auth/me`
Retrieve the profile of the currently authenticated user.
- **Requires Auth**: Yes (Cookie)
- **Response**: User object containing `id`, `email`, and `name`.

### `POST /api/auth/change-password`
Change the password for the currently authenticated user.
- **Requires Auth**: Yes (Cookie)
- **Body**: 
  ```json
  {
    "currentPassword": "OldPassword1",
    "newPassword": "NewPassword2"
  }
  ```

### `POST /api/auth/forgot-password`
Request a password reset link (typically sends an email).
- **Body**: 
  ```json
  {
    "email": "user@example.com"
  }
  ```

### `POST /api/auth/reset-password`
Reset the password using a valid reset token.
- **Body**: 
  ```json
  {
    "token": "reset-token-string",
    "password": "NewPassword1"
  }
  ```

## Data & Analysis

All analysis endpoints are located under `/api` and **require authentication**. 
The `:dataset` parameter specifies the data context (e.g., `global`, `india`).

### `GET /api/overview`
Get a high-level overview of the pipeline results, including available datasets, winning models, and overall metrics.
- **Response**: `{ disclaimer, forecastHorizonMonths, datasets, winners, metrics }`

### `GET /api/gold/:dataset`
Retrieve the base historical gold price series for the specified dataset.
- **Response**: `{ dataset, series: [{ date, price }, ...] }`

### `GET /api/analysis/:dataset`
Get historical data aggregated on a yearly and monthly basis for trend analysis.
- **Response**: `{ dataset, historical, yearly, monthly }`

### `GET /api/seasonality/:dataset`
Get seasonality decomposition analysis for the dataset.
- **Response**: `{ dataset, ...seasonalityData }`

### `GET /api/stationarity/:dataset`
Get stationarity test results (e.g., ADF test statistics and p-values).
- **Response**: `{ dataset, ...stationarityData }`

### `GET /api/models/:dataset`
Get detailed model evaluation results, comparisons, and performance metrics.
- **Response**: `{ dataset, ...modelsData }`

### `GET /api/forecast/:dataset`
Get future price forecasts generated by the winning model, appended to the historical series.
- **Response**: `{ dataset, historical, ...forecastData, disclaimer, forecastModelNote }`
